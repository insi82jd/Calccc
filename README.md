# تطبيق الحاسبة (Dark AMOLED Calculator)

يحتوي هذا الأرشيف على الملفات الجاهزة لبناء ملف APK لتطبيق الحاسبة تلقائياً عبر GitHub Actions.

## محتويات الملف:
- `main.dart`: الكود المصدري للحاسبة بلغة Dart / Flutter.
- `.github/workflows/build.yml`: المسار الجاهز لـ GitHub Actions.
- `build.yml`: نسخة إضافية من ملف البناء في المسار الرئيسي في حال كان مدير الملفات لديك يخفي المجلدات التي تبدأ بنقطة (`.github`).
